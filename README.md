# Knowledge-Vault

**An Agentic RAG-based Multi-Agent System for Automated Generation of Syllabus-Aligned Interactive Study Material**

Enter a subject's requirements (university, course, semester, subject, syllabus). A team of AI agents researches the web, verifies its sources, and generates exam-ready study material: interactive e-books, PDF exam notebooks, flashcards and quizzes.
